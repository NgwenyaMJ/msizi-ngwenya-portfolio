About

Building technology from problem to working product.

I’m Msizi Ngwenya, a software developer focused on designing and building practical digital solutions.

I work across websites, web applications, software systems, dashboards and AI-powered tools, approaching each project from both a technical and problem-solving perspective. My focus is not simply writing code — it is understanding what needs to work, structuring the solution properly and turning the idea into something people can actually use.

I work hands-on across planning, interface development, system logic, testing, improvement and deployment, using modern development tools and AI-assisted workflows where they meaningfully improve speed and quality.

My technical foundation also spans IT systems, networking, cybersecurity, cloud fundamentals, systems administration and Microsoft Azure fundamentals.
